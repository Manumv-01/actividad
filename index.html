El Liceo Francés Paul Valéry es una institución bilingüe con homologación oficial de la República Francesa, miembro de la red AEFE.

  • Educación desde preescolar hasta bachillerato
  • Certificaciones en francés, inglés y portugués
  • Red AEFE — Agence pour l'Enseignement Français à l'Étranger
  • Campus de 12 hectáreas con instalaciones de primer nivel
  • Comunidad activa de familias y ex-alumnos en todo el mundo

Nuestra propuesta

¿Por qué elegirnos?

Más de cinco décadas formando ciudadanos del mundo desde Cali.

🌍

Multilingüismo

Formación en francés, inglés, portugués y español desde los primeros años, abriendo puertas en todo el mundo.

🏅

Red AEFE

Somos parte de la red oficial francesa de enseñanza en el exterior, con homologación y estándares internacionales.

🏊

Campus excepcional

12 hectáreas con piscina olímpica, zonas deportivas, laboratorios y amplios espacios al pie de los Farallones.

👨‍🏫

Docentes de excelencia

Planta docente certificada y bilingüe, con formación continua y metodologías pedagógicas actualizadas.

🎓

Proyección internacional

Nuestros egresados acceden a universidades de Francia, Colombia, EE.UU. y Europa con reconocimiento inmediato.

❤️

Comunidad

Una comunidad educativa unida, con familias comprometidas y una red de ex-alumnos activa en todo el mundo.

¿Cómo se construyó esta página?

Una single-page hecha con las tecnologías base de la web — HTML, CSS y JavaScript puro — sin frameworks ni librerías externas.

HTML

Estructura semántica

  • Etiquetas semánticas: <nav>, <section>, <footer>
  • Un solo archivo — toda la página en un HTML
  • Anclas con id para navegar entre secciones
  • Atributo alt en imágenes para accesibilidad
<!-- cada sección tiene su id --> <section id="nosotros"> <h2>Quiénes somos</h2> </section>
CSS

Estilos modernos

  • Variables CSS (:root) para colores reutilizables
  • CSS Grid para la galería y las tarjetas
  • Flexbox para la navbar y las listas
  • Animaciones con transition y @keyframes
  • Diseño responsivo con @media queries
:root { --azul: #0d2b6e; --rojo: #c62828; } .gallery-grid { display: grid; grid-template-columns: repeat(3, 1fr); }
JavaScript

Interactividad

  • Navbar que cambia color al hacer scroll
  • IntersectionObserver para animar elementos al aparecer
  • Efecto parallax sutil en el hero
  • Lightbox para ver imágenes ampliadas
  • Cierre con tecla Escape
// Animar al entrar en pantalla new IntersectionObserver(entries => { entries.forEach(e => { if (e.isIntersecting) e.target.classList.add('visible'); }); }).observe(elemento);
